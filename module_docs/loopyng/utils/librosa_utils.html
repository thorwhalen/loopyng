loopyng.utils.librosa_utils

A few utils (specshow, melspectrogram) vendored from librosa.

This code was copied from parts of librosa, and adapted, so as to be able to use targeted functionality with less dependencies and manual installation (namely for libsndfile) than librosa has.

Librosa can be found here: https://librosa.org/

loopyng.utils.librosa_utils.get_cmap(name, lut=None)[source]

Look up a named colormap, optionally resampled down to lut colors.

Stands in for matplotlib.cm.get_cmap, which the vendored librosa code was written against and which no longer exists: deprecated in matplotlib 3.7 and removed in 3.11. The supported spelling is the colormap registry (matplotlib.colormaps, since 3.5) plus Colormap.resampled (since 3.6), which is why the viz extra floors matplotlib at 3.6.

Kept as a module-level function rather than an optional_from binding so that a missing matplotlib is reported against matplotlib itself, which is the package the user would actually install.

Parameters:

  • name – A registered colormap name, e.g. "magma"

  • lut – If given, resample the colormap to this many colors

Returns:

A matplotlib.colors.Colormap
